A [make.fun](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) bounty entry: send exactly one letter, A to Z, standing for the word that describes your day.

## The entry

**Z** — for *zombie*, a day spent shuffling through on zero sleep.

Z won the rubric over five other candidates (U for unhinged, F for fried, C for chaotic, W for wiped out, H for hectic): the zombie picture is the most vivid and specific, it lands as a joke at once, it is a true report of a real day, and the letter fits the word — Z is also for *zero sleep*, the same day from a second angle.

## What it does

`main.py` (pure Python standard library, deterministic) writes exactly one character, `Z` with no trailing newline, to `/output/entry.txt` — 1 byte, inside the gate of 1 to 1 characters.

## How to run

```sh
python3 main.py
cat /output/entry.txt  # Z
```
